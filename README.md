# Proyecto de Procesamiento de Señales: Clasificación de Audios con RNN y CNN

Este repositorio contiene el archivo y link del código, los parámetrosm, el informe correspondientes al proyecto de análisis y clasificación de señales de audio de procesamiento de señales 1

# Contenido del Repositorio

* `proyectoseñales.ipynb`: Notebook que contiene todo el código , desde el preprocesamiento y análisis espectral (FFT/DFT, Mel-Spectrogram) hasta el entrenamiento y evaluación de los modelos.
* `Proyecto2_FINAL.pdf`: Documento con el informe del diseño usado, la metodología y los resultados obtenidos.
* `hiperparametros.json`: Archivo clos hiperparámetros utilizados para compilar y entrenar las redes.
* `WhatsApp Video 2026-05-11 at 6.44.44 PM.mp4`: Video demostrativo y explicativo de la ejecución y resultados del proyecto.
